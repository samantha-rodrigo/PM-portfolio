# Samantha Rodrigo — PM Portfolio

Personal portfolio site built with Next.js, TypeScript, and Tailwind CSS. Showcases product management case studies and side projects.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Content

- `app/` — pages (home, about, work, projects, contact)
- `components/` — reusable UI (Header, Footer, cards, social links)
- `lib/site.ts` — site-wide config (name, email, social links)
- `lib/content.ts` — case study and project copy

## Deployment

Deployed on [Vercel](https://vercel.com). Pushing to `main` triggers a new deployment automatically.
